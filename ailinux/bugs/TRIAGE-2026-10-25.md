# WineHQ bug triage 2026-10-25

Official source: https://list.winehq.org/hyperkitty/list/wine-announce@list.winehq.org/thread/BXK6IO4YFZW4O5CABDN5SOOFY3ZYTJP3/

Wine 11.20 already includes 24 fixes. Do not duplicate these patches:
- #60383 cmd.exe overflow for quoted /c command longer than MAX_PATH
- #60484 large /etc/hosts stalls wineboot
- #60408 Media Foundation DXGI_FORMAT_R8_UINT video failure
- #58418 InternetQueryOptionW NULL buffer crash
- #60421 incomplete cldapi crashes OneDrive
- #60328 FL Studio menu hover mis-selection

Wine 11.19 includes #60380 (.NET Framework 4.8 Decimal Math.Round) and #60345 (RSA/HMAC). These are also already in our 11.20 base.

The #60383 minimal local regression probe has run against the new Wine 11.20 engine and did not crash at 256, 1024, 4096 or 8192 characters. A return code of 255 at 8192 is NOT a proof of successful command execution, only no observed crash.

Unresolved local investigations: Microsoft VC++ v14 installer returned 130 for x86/x64, with only x64 registry version verified. Winetricks .NET 4.8 install is not verified and may switch Windows version during installation. Neither is a validated upstream Wine bug yet.

For each new upstream fix: confirm bug status and version, reproduce with a failing Win32/Win64 test, identify cause, add a minimal licensed patch, run the native Wine and application regression suites, then submit upstream if valid. No speculative patching.
